FastDraw is a text format for diagrams.

Claude Code, Codex and Copilot write it from a guide and run a checker over what they wrote. You open the same file on a canvas and move things by hand; each box you move changes its own line and no other.

Three steps, then ask for a diagram.

The setup writes a short instruction file that points your agent at the guide. Nothing else is installed.

1

Run one command in your repository

npx fastdraw setup claude adds a skill for Claude Code. setup agents and setup copilot do the same for Codex, OpenCode and Copilot. Needs Node 20.

2

Ask for a diagram

“Draw this repo's architecture as docs/architecture.fdraw.” The agent reads the guide for that kind of diagram and writes the file.

3

Open it and move things

npx fastdraw open docs/architecture.fdraw opens the editor. What you move is saved into the file, and the agent reads it before its next edit.

From a request to a file in the repo.

  1. Ask in your agent's chatName the file and say what it should show.
  2. The agent writes and checks itIt reads the guide for the kind you asked for, writes the file, and runs fastdraw check until nothing is reported.
  3. Open it and move thingsDrag, retype, recolour. Each change rewrites only its own line.
  4. Commit it with the codeThe diff is a few lines. PNG and SVG exports carry the text inside, so they can be opened again.

The agent runs the checker before it answers.

fastdraw check reports overlapping boxes, text that does not fit and lines with no room, each with its line number. The agent fixes them before you see the diagram.

$ fastdraw check docs/checkout.fdraw
line 9: "Cache" overlaps "Catalog" (line 8)
line 15: the line "reads" has no room between them
# the agent moves Cache back into the Data zone
$ fastdraw check docs/checkout.fdraw
ok: no problems found
