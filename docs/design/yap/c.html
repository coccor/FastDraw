Diagrams that live next to the code.

FastDraw is a text format for diagrams. Your coding agent writes the file from a guide, checks it, and commits it with the change it describes. You can open it on a canvas and move things by hand.

Diagrams of this codebaseNot in the repository

Most diagrams of a codebase live outside it.

They are drawn once, for a meeting or a document, in a tool the next person may not have. The code keeps changing and the drawing does not.

  • An agent can update a text file in the same commit as the code.
  • A reviewer sees the change to the diagram as a few changed lines.
  • Anyone with a browser can open it; nothing is uploaded.

Set up in three steps.

1

Run one command in your repository

npx fastdraw setup claude adds a skill for Claude Code. setup agents and setup copilot do the same for Codex, OpenCode and Copilot. Needs Node 20.

2

Ask for a diagram

“Draw this repo's architecture as docs/architecture.fdraw.” The agent reads the guide for that kind of diagram and writes the file.

3

Open it and move things

npx fastdraw open docs/architecture.fdraw opens the editor. What you move is saved into the file, and the agent reads it before its next edit.

One file, twelve looks.

Write look engraved as the first line and the same file is drawn another way.

Set it up in your repository.

FastDraw is free and open source under the MIT licence. The tool runs through npx, so there is nothing else to install.
