Diagrams your agent writes as text.

A FastDraw diagram is a short text file that sits in your repository. Agents write it from a guide and check it; you open it on a canvas and move things by hand.

A guide for 44 kinds of diagram.

The agent reads the guide for the kind you ask for. Every example below was written by an agent from its guide and is in the repository unchanged.

Also: bar, data flow, dependency, deployment, ER, exploded, fishbone, heatmap, journey, kanban, layers, loop, org chart, pyramid, quadrant, radar, timeline, treemap, UML class, Venn, Wardley map and more.

Set up in three steps.

1

Run one command in your repository

npx fastdraw setup claude adds a skill for Claude Code. setup agents and setup copilot do the same for Codex, OpenCode and Copilot. Needs Node 20.

2

Ask for a diagram

“Draw this repo's architecture as docs/architecture.fdraw.” The agent reads the guide for that kind of diagram and writes the file.

3

Open it and move things

npx fastdraw open docs/architecture.fdraw opens the editor. What you move is saved into the file, and the agent reads it before its next edit.

The agent runs the checker before it answers.

fastdraw check reports overlapping boxes, text that does not fit and lines with no room, each with its line number.

$ fastdraw check docs/checkout.fdraw
line 9: "Cache" overlaps "Catalog" (line 8)
line 15: the line "reads" has no room between them
# the agent moves Cache back into the Data zone
$ fastdraw check docs/checkout.fdraw
ok: no problems found

Set it up in your repository.

FastDraw is free and open source under the MIT licence. The tool runs through npx, so there is nothing else to install.

$ npx fastdraw setup claudeCopy
