The home page, after yapstudio.app

Three directions for fastdraw.dev that borrow from Yap Studio's home page. They are static prototypes drawn with the real renderer; the live page has not changed. Open a.html, b.html and c.html for the full pages; node docs/design/yap/build.ts rebuilds them.

What Yap does that FastDraw's page does not

  • Type: a heavy, tightly set sans headline that ends in an italic serif clause. All three directions use Geist 800 with Instrument Serif Italic, which is already in fonts/. The headlines stay plain statements, not Yap's two-beat slogans.
  • Annotated product shot: yellow monospace tags with leader lines naming what each part of the hero does. For FastDraw, each tag can be the box's actual line from the file.
  • Style pills under the hero (Headline, Editorial, Candy), which map directly onto looks.
  • Full-width bands alternating grey and white, one saturated colour band for the gallery, and a yellow closing band.
  • Numbered setup cards (1, 2, 3 in a serif numeral), progress tabs that advance on their own, a sideways carousel with captions, and a dark card for the "checked before you see it" step, which maps onto fastdraw check.
  • Pill-shaped buttons. Yap's are black; here they stay indigo.

Open questions

  • Yap's grey is warm, close to paper. These use a neutral grey (#f3f3f5) to stay off the paper look; the warm one is a one-line change if you want it.
  • Parts mix across directions: for example, A's tagged hero with B's looks carousel and C's progress tabs in place of A's walkthrough list.
